# TCH-Bootcamp-Data-Science---Finance-Economics-Time-Series-Analysis
TCH Bootcamps Data Science group project (NYU, Fall 2026). Time-series analysis and forecasting of stock indices and US macroeconomic indicators (GDP, inflation, interest rates, unemployment) using EDA, feature engineering, baseline ML, VAR, and LSTM/GRU models, with an optional Streamlit dashboard.
